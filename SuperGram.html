1. Account

आप अपने account की जानकारी सही रखें और password किसी दूसरे व्यक्ति के साथ share न करें।

ऐसा photo, video, text या message upload न करें जिससे किसी व्यक्ति को नुकसान, धोखा, harassment या privacy violation हो।

3. Privacy

Public account में profile photo और public profile information दूसरे users देख सकते हैं। Private account में profile photo को दूसरे users से छिपाया जाएगा।

4. Messages

दूसरे users को spam या unwanted messages न भेजें। Block feature का उपयोग unwanted contact रोकने के लिए करें।

5. Uploads

आपके uploads Cloudinary media storage और Super Gram database में आवश्यक metadata के साथ store हो सकते हैं।

6. Changes & Updates

Super Gram के features और Terms समय-समय पर update हो सकते हैं।
